Paquetes

Design Lib está dividido en cinco paquetes independientes. Instala solo lo que necesitas.

token
@aolmosn/tokens

Variables CSS semánticas para colores, tipografía, espaciado, radios y sombras. Incluye tema claro y oscuro.

widgets
@aolmosn/web-components

Componentes UI construidos con Lit 3. Funcionan en cualquier framework o en HTML puro.

engineering
@aolmosn/angular

Wrappers Angular con tipado completo, formularios reactivos y two-way binding.

palette
@aolmosn/styles

SCSS con utilidades de layout responsivo: grid, flex, gap, breakpoints mobile-first.

data_object
@aolmosn/core

Tipos compartidos, constantes y utilidades internas usadas por los demás paquetes.

Instalación

Instala los paquetes que necesites desde npm:

Terminal 
# Instalación completa (recomendado para Angular)
npm install @aolmosn/tokens @aolmosn/web-components @aolmosn/angular @aolmosn/styles

# Solo web components (sin Angular)
npm install @aolmosn/tokens @aolmosn/web-components

Tokens CSS

Los tokens son el fundamento del sistema de diseño. Deben cargarse una vez en tu aplicación. El archivo CSS incluye las variables para tema claro y oscuro.

Con Angular (angular.json)

Agrega el archivo CSS en la sección styles de tu angular.json:

angular.json 
"styles": [
  "src/styles.scss",
  "node_modules/@aolmosn/tokens/dist/tokens.css"
]

En HTML puro

index.html 
<link rel="stylesheet"
      href="node_modules/@aolmosn/tokens/dist/tokens.css">

Wrappers Angular

Cada componente Angular es un standalone que importas directamente en tu componente o módulo.

Importar un componente

mi-componente.ts 
import { Component } from '@angular/core';
import { UiButton }  from '@aolmosn/angular/button';
import { UiSelect }  from '@aolmosn/angular/select';  // misma idea

@Component({
  standalone: true,
  imports: [UiButton, UiSelect],
  template: `
    <ui-button (ui-click)="guardar()">Guardar</ui-button>
  `,
})
export class MiComponente { ... }

Paquetes secundarios disponibles

@aolmosn/angular/button @aolmosn/angular/alert @aolmosn/angular/check-box @aolmosn/angular/chip @aolmosn/angular/kebab @aolmosn/angular/onboarding @aolmosn/angular/radio-button @aolmosn/angular/text-field @aolmosn/angular (entry point principal — todos los componentes)

Formularios reactivos

form.component.ts 
import { ReactiveFormsModule } from '@angular/forms';
import { UiButton }           from '@aolmosn/angular/button';
import { UiCheckBox }         from '@aolmosn/angular/check-box';

@Component({
  standalone: true,
  imports: [ReactiveFormsModule, UiButton, UiCheckBox],
  template: `
    <form [formGroup]="form">
      <ui-check-box
        formControlName="acepto"
        label="Acepto los términos"
      ></ui-check-box>
      <ui-button (ui-click)="submit()">Enviar</ui-button>
    </form>
  `,
})

Web Components (sin Angular)

Importa los componentes directamente como módulos ES en cualquier entorno.

main.js 
// Importar componentes individuales (tree-shaking)
import '@aolmosn/web-components/button';
import '@aolmosn/web-components/select';

// O el bundle completo
import '@aolmosn/web-components';
index.html 
<ui-button>Guardar</ui-button>

<ui-text-input
  label="Correo"
  placeholder="correo@empresa.com"
  required
></ui-text-input>

Estilos y utilidades

El paquete @aolmosn/styles incluye utilidades SCSS de layout. Importa en tu styles.scss principal:

styles.scss 
// Todas las utilidades (grid, flex, gap, padding, etc.)
@use '@aolmosn/styles';

// Solo los mixins de breakpoints
@use '@aolmosn/styles/mixins';

Clases de layout disponibles

Flex
flex-row flex-col flex-wrap flex-a-c flex-j-sb
Grid responsivo
grid-1 md:grid-2 lg:grid-3 xl:grid-4
Gap
gap-4 gap-8 gap-16 gap-default gap-32
Ancho
w-full w-fit

Ejemplo

template.html 
<!-- 1 columna en móvil, 2 en tablet -->
<section class="grid-1 md:grid-2 gap-default w-full">
  <div class="card">...</div>
  <div class="card">...</div>
</section>

<!-- Botones con wrap en móvil -->
<div class="flex-row flex-wrap gap-8">
  <ui-button>Cancelar</ui-button>
  <ui-button>Guardar</ui-button>
</div>

Temas claro y oscuro

Los tokens incluyen variables para ambos temas. El cambio es automático vía prefers-color-scheme. También puedes forzarlo con el atributo data-theme en el elemento raíz.

Forzar tema desde código 
// Forzar tema oscuro
document.documentElement.setAttribute('data-theme', 'dark');

// Forzar tema claro
document.documentElement.setAttribute('data-theme', 'light');

// Volver a seguir el sistema operativo
document.documentElement.removeAttribute('data-theme');
lightbulb

Los web components leen los tokens desde el DOM a través del Shadow DOM, por lo que el cambio de tema se propaga automáticamente a todos los componentes sin necesidad de reinicializarlos.
