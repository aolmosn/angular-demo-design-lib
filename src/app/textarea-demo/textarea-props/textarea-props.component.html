API del componente

Propiedades

Propiedad Atributo HTML Tipo Default Descripción
label label string '' Etiqueta visible del campo. Si está vacío, no se renderiza el <label>.
value value string '' Valor actual del textarea.
placeholder placeholder string '' Texto placeholder nativo.
name name string '' Atributo name para formularios HTML.
rows rows number 3 Número de filas visibles del <textarea> nativo. Controla la altura inicial.
resize resize 'vertical' | 'horizontal' | 'both' | 'none' 'vertical' Dirección en que el usuario puede redimensionar el textarea. 'none' lo deshabilita.
maxLength max-length number undefined Límite máximo de caracteres. Al superar el límite se activa el estado de error visual y se muestra el contador.
showCount show-count boolean false Muestra el contador de caracteres escritos. Se activa automáticamente si se define max-length.
disabled disabled boolean false Deshabilita el campo. Visualmente atenuado, sin interacción y sin resize.
readonly readonly boolean false Solo lectura. Se puede copiar pero no editar. Deshabilita el resize.
required required boolean false Marca el campo como obligatorio. Agrega asterisco rojo a la etiqueta.
invalid invalid boolean false Activa el estado de error visual. Muestra error-text si está definido.
helperText helper-text string '' Texto de ayuda. Se oculta cuando invalid es true y hay un error-text.
errorText error-text string '' Mensaje de error. Solo visible cuando invalid es true.

Eventos

Evento Detail Descripción
ui-input { value: string } Se emite en cada keystroke.
ui-change { value: string } Se emite al confirmar el valor (blur). Equivalente al evento change nativo.
ui-focus {} El textarea recibió el foco.
ui-blur {} El textarea perdió el foco.

CSS Custom Properties

Variable Default Descripción
--ui-textarea-min-height 80px Altura mínima del campo. Útil para garantizar un tamaño base independiente de rows.
--ui-textarea-resize valor de resize Controlado internamente por la prop resize. Puede sobreescribirse vía CSS desde el host.

CSS Parts

Part Elemento Descripción
::part(field) .input-wrap Contenedor raíz del componente.
::part(label) <label> Etiqueta del campo.
::part(textarea) <textarea> Textarea nativo.
::part(helper) .input-helper Texto de ayuda.
::part(error) .input-error-msg Mensaje de error.
::part(count) .char-count Contador de caracteres.
