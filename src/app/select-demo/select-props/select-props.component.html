Propiedades

Propiedad Atributo HTML Tipo Default Descripción
label label string '' Etiqueta visible sobre el campo
placeholder placeholder string 'Selecciona una opción' Texto cuando no hay valor seleccionado
value value string '' Valor de la opción seleccionada (debe coincidir con SelectOption.value)
options — SelectOption[] [] Array de opciones. Solo se puede pasar como propiedad DOM ([options]="...")
disabled disabled boolean false Deshabilita toda interacción con el componente
readonly readonly boolean false Muestra el valor pero no permite cambiarlo
invalid invalid boolean false Activa el estado de error visual. Muestra error-text si está definido
helperText helper-text string '' Texto de ayuda bajo el campo. Se oculta cuando hay error activo
errorText error-text string '' Mensaje de error. Solo visible cuando invalid="true"
searchThreshold search-threshold number 8 Cantidad mínima de opciones para mostrar el campo de búsqueda
smartPosition smart-position boolean false Abre el dropdown hacia arriba si no hay espacio suficiente hacia abajo

Eventos

Evento detail Descripción
ui-change {{ '{' }} value: string, option: SelectOption {{ '}' }} Se emite al seleccionar una opción. No se emite si el valor no cambia

Tipo SelectOption

Campo Tipo Requerido Descripción
value string sí Identificador único de la opción
label string sí Texto visible en el listado
group string no Nombre del grupo al que pertenece la opción. Las opciones del mismo grupo se agrupan visualmente
disabled boolean no Deshabilita esta opción individualmente
icon string no Nombre del ícono de Material Icons, e.g. "person"
description string no Texto secundario visible bajo el label de la opción
