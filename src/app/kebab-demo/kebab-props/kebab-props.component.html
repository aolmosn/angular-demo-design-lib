Propiedades

ui-kebab-container

Propiedad Tipo Default Descripción
hideList boolean true Controla si la lista está visible. true = cerrado
triggerElement Element | null null Elemento externo usado como trigger. Si es null se muestra el ícono ⋮ interno

ui-kebab-option

Propiedad Atributo HTML Tipo Default Descripción
icon icon string '' Nombre del ícono de Material Icons (ej. 'download'). El texto de la opción va como contenido del elemento

Métodos públicos de ui-kebab-container

Método Descripción
show() Abre el menú y empieza a trackear posición
hide() Cierra el menú y detiene el tracking
toggle() Alterna entre abierto y cerrado
setTrigger(el) Asigna un elemento externo como trigger. El posicionamiento se calcula respecto a ese elemento

Evento Emitido por detail Descripción
