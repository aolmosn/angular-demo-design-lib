API del componente

Propiedades

Propiedad (JS) Atributo HTML Tipo Default Descripción
steps — (solo property) StepConfig[] [] Definición de los pasos. Cada elemento tiene label (requerido) y description (opcional). Se pasa como propiedad JS.
current current number 1 Paso activo (1-based). Para modo controlado, actualiza este valor al recibir el evento ui-step. El componente también funciona sin binding (modo no controlado).
valid — (solo property) boolean[] [] Controla si el botón "siguiente" está habilitado por paso. valid[0] controla si se puede avanzar del paso 1 al 2, valid[1] del paso 2 al 3, etc. undefined (sin entrada) se trata como true.

Tipo StepConfig

CampoTipoDescripción
label string Título del paso. Aparece en el tooltip del dot y en la fila de info.
description? string Subtítulo opcional debajo del label.

Eventos emitidos

EventoDetailDescripción
ui-step StepperChangeDetail Se emite cada vez que cambia el paso activo (via botones, dot click o evento externo).

Tipo StepperChangeDetail

CampoTipoDescripción
step number Número del nuevo paso activo (1-based).
prev number Número del paso anterior.
direction 'next' | 'prev' | 'jump' Origen del cambio: next (botón →), prev (botón ← o dot click hacia atrás), jump (evento ui-stepper-go).

Eventos externos (escuchados por el componente)

EventoDetailDescripción
ui-stepper-next — Avanza al paso siguiente si el paso actual es válido.
ui-stepper-prev — Retrocede al paso anterior si hay uno.
ui-stepper-go { step: number } Salta directamente al paso indicado (1-based). Útil para reset o navegación programática.

CSS Parts

PartElemento
headerBarra superior con dots + counter + botones.
infoFila con label del paso actual y porcentaje.
barContenedor de la barra de progreso.
panelsContenedor de los slots de contenido.

Slots de contenido

SlotDescripción
step-1, step-2, … step-N Contenido del paso correspondiente. El componente solo muestra el slot del paso activo y oculta los demás. El contenido sigue en el DOM (no se destruye), lo que preserva el estado de los formularios.
