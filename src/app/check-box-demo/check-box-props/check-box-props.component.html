Propiedades

Propiedad Atributo HTML Tipo Default Descripción
label label string '' Texto que se muestra junto al checkbox
name name string '' Atributo name del input nativo
value value string 'on' Valor del input nativo al enviarse en un form HTML
checked checked boolean false Estado seleccionado. Con Reactive Forms se controla vía FormControl
disabled disabled boolean false Deshabilita la interacción. Con Reactive Forms usar control.disable()
required required boolean false Marca el campo como obligatorio
indeterminado indeterminado boolean false Estado intermedio (ni marcado ni desmarcado). Se usa en el patrón "seleccionar todo". Al hacer click el usuario lo resetea a false
