Propiedades

Propiedad Atributo HTML Tipo Default Descripción
content content string '' Texto que se muestra en el tooltip. Si está vacío el tooltip no aparece.
position position TooltipPosition 'top' Posición del tooltip respecto al trigger. Valores: 'top' · 'bottom' · 'left' · 'right'

Contenido

Mecanismo Descripción
<slot> El elemento trigger se pasa como contenido entre las etiquetas. El tooltip aparece al hacer hover o focus sobre ese elemento.
