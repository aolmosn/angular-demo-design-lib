Propiedades

Inputs de ui-onboarding

Propiedad Tipo Default Descripción
steps OnboardingStep[] [] Array de pasos del recorrido. Cada paso necesita selector, title y description

Interfaz OnboardingStep

Campo Tipo Descripción
selector string Selector CSS del elemento a resaltar (ej. '#mi-id', '.mi-clase')
title string Título que muestra el coachmark sobre el elemento
description string Descripción o explicación del paso

Métodos públicos (via @ViewChild o ElementRef)

Método Descripción
start() Inicia el recorrido desde el primer paso
stop() Cierra el onboarding y emite ui-onboarding-close
next() Avanza al paso siguiente. Si es el último, cierra y emite ui-onboarding-finish
prev() Retrocede al paso anterior

Eventos

Evento detail Descripción
ui-onboarding-step {{ '{' }} step, index {{ '}' }} Se emite al navegar a cada paso. index es base 0
ui-onboarding-finish — Se emite al completar el último paso
ui-onboarding-close — Se emite al cerrar el onboarding con stop()
