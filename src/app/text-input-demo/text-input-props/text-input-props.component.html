API del componente

Propiedades

Propiedad Atributo HTML Tipo Default Descripción
label label string '' Etiqueta visible del campo. Si está vacío, no se renderiza el <label>.
value value string '' Valor actual del input. Modificable desde el exterior vía property binding.
placeholder placeholder string '' Texto de placeholder nativo del input.
name name string '' Atributo name del input nativo para formularios HTML.
type type 'text' | 'email' | 'password' | 'number' | 'search' | 'url' | 'tel' 'text' Tipo del elemento <input> nativo.
size size 'sm' | 'md' | 'lg' 'md' Tamaño del campo: sm 32px, md 40px (default), lg 48px.
disabled disabled boolean false Deshabilita el campo. Visualmente atenuado y sin interacción.
readonly readonly boolean false Campo de solo lectura. Se puede copiar pero no editar.
required required boolean false Marca el campo como obligatorio. Agrega asterisco rojo a la etiqueta.
invalid invalid boolean false Activa el estado de error visual. Muestra error-text si está definido.
helperText helper-text string '' Texto de ayuda secundario. Se oculta cuando invalid es true y hay un error-text.
errorText error-text string '' Mensaje de error. Solo visible cuando invalid es true.

Eventos

Evento Detail Descripción
ui-input { value: string } Se emite en cada keystroke. Equivalente a input nativo pero dentro del shadow DOM.
ui-change { value: string } Se emite al confirmar el valor (blur o Enter). Equivalente a change nativo.
ui-focus {} El input nativo recibió el foco.
ui-blur {} El input nativo perdió el foco.

CSS Parts

Part Elemento Descripción
::part(field) .input-wrap Contenedor raíz del componente.
::part(label) <label> Etiqueta del campo.
::part(input) <input> Input nativo.
::part(helper) .input-helper Texto de ayuda.
::part(error) .input-error-msg Mensaje de error.
