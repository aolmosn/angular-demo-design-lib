Propiedades

Propiedad Atributo HTML Tipo Default Descripción
mode mode 'single' | 'range' 'single' Modo de selección. single: una fecha, cierra al seleccionar. range: rango inicio/fin, se confirma con el botón "Listo".
value value string (ISO) '' Fecha seleccionada en modo single. Formato YYYY-MM-DD.
from from string (ISO) '' Fecha de inicio del rango confirmado en modo range. Formato YYYY-MM-DD.
to to string (ISO) '' Fecha de fin del rango confirmado en modo range. Formato YYYY-MM-DD.
label label string '' Etiqueta visible sobre el campo.
placeholder placeholder string Auto según modo Texto cuando no hay valor seleccionado. Default: 'Selecciona una fecha' / 'Selecciona un rango'.
minDate min-date string (ISO) '' Fecha mínima seleccionable. Las fechas anteriores aparecen deshabilitadas en el calendario.
maxDate max-date string (ISO) '' Fecha máxima seleccionable. Las fechas posteriores aparecen deshabilitadas en el calendario.
locale locale string 'es-CL' Locale para el formateo del calendario y del valor mostrado en el trigger. Ej: 'es-CL', 'en-US', 'pt-BR'.
invalid invalid boolean false Activa el estado de error visual en el campo.
errorText error-text string '' Mensaje de error que aparece bajo el campo cuando invalid es true.
helperText helper-text string '' Texto de ayuda que aparece bajo el campo cuando no hay error.
required required boolean false Muestra el asterisco * junto al label. No añade validación nativa (la valida el formulario consumidor).
disabled disabled boolean false Deshabilita el campo: no abre el popover, reduce la opacidad.
size size 'sm' | 'md' | 'lg' 'md' Altura del trigger: sm = 32px, md = 40px, lg = 48px.
name name string '' Nombre del campo, útil cuando se integra en formularios nativos.

Eventos

Evento Detail (single) Detail (range) Descripción
ui-change { mode: 'single', value: string, date: Date } { mode: 'range', from: string, to: string, fromDate: Date, toDate: Date } Se emite al confirmar una fecha (single: al hacer click en el calendario) o un rango (range: al pulsar el botón "Listo"). El campo value/from/to es ISO YYYY-MM-DD.
ui-clear — {} Se emite solo en modo range al pulsar el botón × en el trigger. Limpia from y to.

CSS Parts

Part Elemento Descripción
::part(wrap) .input-wrap Contenedor externo que agrupa label + field + helper.
::part(label) label Elemento de la etiqueta.
::part(field) .input-field El trigger visible (el "input"). Recibe los class modifiers de estado.
::part(error) .input-error-msg Mensaje de error bajo el field.
::part(helper) .input-helper Texto de ayuda bajo el field.
