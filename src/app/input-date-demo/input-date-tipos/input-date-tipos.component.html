Fecha única mode="single"

Al seleccionar una fecha el popover se cierra automáticamente y la fecha formateada aparece dentro del campo.

Evento (ui-change)

@if (singleValue) {
value: "{{ singleValue }}" {{ singleEventTs }}
} @else { Sin selección }

Rango de fechas mode="range"

El popover permanece abierto mientras se selecciona el rango. El botón Listo se habilita cuando hay fecha de inicio y fin. El botón × en el trigger limpia el rango confirmado.

Evento (ui-change)

@if (rangeFrom && rangeTo) {
from: "{{ rangeFrom }}" to: "{{ rangeTo }}" {{ rangeEventTs }}
} @else { Sin rango confirmado }
