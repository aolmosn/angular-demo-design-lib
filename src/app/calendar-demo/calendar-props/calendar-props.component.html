Propiedades

Propiedad Atributo HTML Tipo Default Descripción
mode mode 'single' | 'range' 'single' Modo de selección. single selecciona una fecha, range selecciona un rango desde/hasta.
value value string (ISO) '' Fecha seleccionada en modo single. Formato YYYY-MM-DD.
from from string (ISO) '' Fecha de inicio en modo range. Formato YYYY-MM-DD.
to to string (ISO) '' Fecha de fin en modo range. Formato YYYY-MM-DD.
minDate min-date string (ISO) '' Fecha mínima seleccionable. Días anteriores quedan deshabilitados.
maxDate max-date string (ISO) '' Fecha máxima seleccionable. Días posteriores quedan deshabilitados.
minDays min-days number 1 Mínimo de días que debe abarcar el rango (solo range). Los primeros N-1 días después del from quedan deshabilitados.
maxDays max-days number 0 Máximo de días del rango (solo range). 0 significa sin límite.
businessDaysOnly business-days-only boolean false Solo permite seleccionar días hábiles (lunes a viernes). Sábados y domingos quedan deshabilitados.
locale locale string navigator.language Locale para nombres de meses, días y formato de fechas. Ej: 'es-CL', 'en-US'.

Eventos

Evento Modo Detail Descripción
ui-change single { date: Date } El usuario selecciona una fecha.
ui-change range { from: Date, to: Date } El usuario completa la selección del rango.
ui-clear ambos {} El usuario presiona el botón Limpiar.
