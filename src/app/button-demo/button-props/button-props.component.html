Propiedades

Propiedad Atributo HTML Tipo Default Descripción
type type ButtonType 'PRIMARY' Variante visual. Valores: 'PRIMARY' · 'SECONDARY' · 'TERTIARY' · 'LINK' · 'QUINARY'
disabled disabled boolean false Deshabilita el botón. Bloquea el click y aplica estilos de estado deshabilitado
expanded expanded boolean false Aumenta el padding vertical (variante XL). Útil para botones principales de acción
leftIcon leftIcon string '' Nombre del ícono de Material Icons que aparece a la izquierda del texto (ej. 'add', 'edit')
rigthIcon rigthIcon string '' Nombre del ícono de Material Icons que aparece a la derecha del texto (ej. 'arrow_forward')

Eventos

Evento Angular Evento nativo (CustomEvent) Descripción
(ui-click) ui-click El usuario hace click en el botón y no está deshabilitado. Usar (ui-click) en el template (no (click))

Contenido

Mecanismo Descripción
<ng-content> / <slot> El texto del botón se pasa como contenido entre las etiquetas: <ui-button>Texto</ui-button>
