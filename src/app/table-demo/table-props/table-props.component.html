API del componente

Propiedades

Propiedad (JS) Atributo HTML Tipo Default Descripción
columns — (solo property) TableColumn[] [] Definición de columnas. Se pasa como propiedad JS (no serializable como atributo).
rows — (solo property) Record<string,any>[] [] Array de objetos que representa cada fila de datos.
rowKey row-key string 'id' Nombre del campo que actúa como clave única para cada fila.
selectable selectable boolean false Muestra la columna de checkbox. Hacer clic en una fila también la selecciona.
selectedKeys — (solo property) string[] [] Claves preseleccionadas al inicializar. Al cambiar, sincroniza la selección interna.
paginated paginated boolean false Muestra el paginador en el footer del componente.
page page number 1 Página actual (1-based). Puede controlarse externamente.
pageSize page-size number 10 Número de filas por página.
pageSizeOptions — (solo property) number[] [10, 25, 50, 100] Opciones disponibles en el selector de filas por página.
serverPagination server-pagination boolean false Modo server-side: el componente emite ui-page pero no corta el array rows.
totalItems total-items number undefined Total de ítems para el display "1-10 de N" en modo server-side. Se ignora en modo client-side.
loading loading boolean false Reemplaza las filas por filas skeleton animadas.
skeletonRows skeleton-rows number 5 Número de filas skeleton a mostrar durante la carga.
emptyMessage empty-message string 'No hay datos...' Texto mostrado cuando el array rows está vacío y no está en estado loading.

Tipo TableColumn

Campo Tipo Descripción
key string Nombre del campo en el objeto de datos (row[key]).
label string Texto de la cabecera de la columna.
sortable? boolean Activa el click en cabecera para ordenar. Solo client-side.
align? 'left' | 'center' | 'right' Alineación del contenido de la columna. Default: 'left'.
width? string Ancho CSS explícito (ej: '120px', '10%').
formatter? (value, row) → string Función de formato para transformar el valor antes de mostrarlo.

Eventos

Evento Detail Descripción
ui-select TableSelectDetail Se emite al marcar/desmarcar filas o el select-all.
ui-sort { key: string, direction: 'asc'|'desc' } Se emite al hacer clic en una cabecera sortable.
ui-page TablePageDetail Se emite al cambiar de página o al cambiar el tamaño de página.

Tipo TableSelectDetail

CampoTipoDescripción
selectedKeys string[] Todas las claves seleccionadas actualmente (puede incluir filas de otras páginas).
allSelected boolean Indica si todas las filas visibles en la página actual están seleccionadas.
triggerKey? string Clave de la fila que disparó el cambio. undefined si fue el select-all.

Tipo TablePageDetail

CampoTipoDescripción
page number Número de la nueva página (1-based).
pageSize number Filas por página actualmente configuradas.
totalItems number Total de ítems (calculado o proporcionado con total-items).
totalPages number Total de páginas calculadas.
