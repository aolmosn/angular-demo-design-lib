API del componente

Propiedades

Propiedad Atributo HTML Tipo Default Descripción
value value number | null null Valor numérico en bruto. null representa el campo vacío.
currency currency string '' Código ISO de la moneda actualmente seleccionada (ej: 'CLP', 'USD').
currencies — CurrencyOption[] [] Lista de monedas disponibles. Si está vacío o tiene un solo elemento, el selector no es interactivo.
decimals decimals number undefined Límite de decimales. 0 = solo enteros. Si no se define, se usa el valor de la moneda seleccionada o 2 por defecto.
locale locale string '' Locale para el valor formatted en eventos (ej: 'es-CL', 'en-US'). Default: usa el locale del navegador.
label label string '' Etiqueta visible del campo.
placeholder placeholder string '0' Texto placeholder del input.
name name string '' Atributo name del input nativo.
min min number undefined Valor mínimo. Se aplica al perder el foco (clamp en blur).
max max max undefined Valor máximo. Se aplica al perder el foco (clamp en blur).
disabled disabled boolean false Deshabilita el campo y el selector de moneda.
readonly readonly boolean false Campo de solo lectura. Deshabilita el selector de moneda.
required required boolean false Marca el campo como obligatorio.
invalid invalid boolean false Activa el estado de error visual.
helperText helper-text string '' Texto de ayuda secundario.
errorText error-text string '' Mensaje de error. Solo visible cuando invalid es true.

Eventos

Evento Detail Descripción
ui-input CurrencyInputChangeDetail Se emite en cada keystroke con el valor numérico, código de moneda y string formateado.
ui-change CurrencyInputChangeDetail Se emite al perder el foco (blur). El valor ya tiene aplicado el clamp de min/max.
ui-currency-change { currency: string } Se emite al seleccionar una nueva moneda en el dropdown.
ui-focus {} El input recibió el foco.
ui-blur {} El input perdió el foco.

Tipo CurrencyOption

Campo Tipo Descripción
code string Código ISO de la moneda (ej: 'CLP', 'USD', 'EUR').
symbol string Símbolo para mostrar en el trigger (ej: '$', '€', '£').
name string Nombre descriptivo de la moneda (ej: 'Peso chileno'). Usado en el dropdown.
decimals? number Número de decimales sugerido para esta moneda. Solo aplica si decimals no está definido en el componente.

Tipo CurrencyInputChangeDetail

Campo Tipo Descripción
value number | null Valor numérico puro (sin formato). null si el campo está vacío.
currency string Código de la moneda seleccionada en el momento del evento.
formatted string Cadena formateada según el locale del componente. Útil para mostrar al usuario.
