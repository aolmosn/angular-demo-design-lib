Responsive — prefijos de breakpoint

La mayoría de las clases utilitarias tiene variantes responsive generadas automáticamente. El formato es prefix:clase — aplica la propiedad solo a partir de ese ancho. El sistema es mobile-first: sin prefijo = todos los anchos; con prefijo = desde ese breakpoint en adelante.

Breakpoints disponibles

PrefijoMínimoDispositivo típicoEjemplo de uso
{{ bp.prefix }}: min-width: {{ bp.width }} {{ bp.desc }} {{ bp.prefix }}:flex-col

Sintaxis

HTML
<!-- Sin prefijo: aplica en todos los anchos -->
<div class="flex-col"> ... </div>

<!-- Con prefijo: solo a partir de md (768px) -->
<div class="flex-col md:flex-row"> ... </div>

<!-- Varias columnas según ancho de ventana -->
<div class="grid-1 sm:grid-2 lg:grid-3 xl:grid-4"> ... </div>

<!-- Combinar con spacing -->
<div class="gap-8 md:gap-16 lg:gap-24"> ... </div>

Grupos con variante responsive

GrupoEjemplo sin prefijoCon prefijo
Display flex, hidden, block md:flex, lg:hidden
Flex wrap / grow flex-wrap, flex-1 sm:flex-wrap
Align / Justify items-center, justify-between md:items-start
Grid grid-2, grid-1-2 lg:grid-3, md:grid-2-1
Width w-full, w-6 md:w-6, lg:w-4
Gap / Padding / Margin gap-8, p-16, mt-24 md:gap-16, lg:p-24
Tipografía text-sm, text-lg md:text-md, lg:text-xl
